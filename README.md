# 11:30

밤 11시 30분, 모르는 누군가에게서 연락이 온다. 스마트폰 화면을 그대로 재현한 웹 추리게임입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 설치할 것은 없습니다.

## 플레이 방법

- 잠금화면 비밀번호는 `0000`입니다.
- 폰 속 앱(카카오톡, 전화, 문자, 메모, 인스타, 유튜브, 인터넷, 설정)을 뒤져서 단서를 찾으세요.
- 카카오톡 `(알 수 없음)` 채팅방에서 「너 누구야?」를 눌러 정답을 고릅니다. 기회는 3번입니다.
- 연락한 사람은 게임을 시작할 때마다 6명(희서, 서진, 민지, 준혁, 도윤, 지안) 중에서 무작위로 정해집니다.
