# 11:30

밤 11시 30분, 모르는 누군가에게서 "ㅇㅇ아. 나 알지?"라는 연락이 온다.
스마트폰 화면을 그대로 재현한 웹 게임으로, 나를 좋아하는 사람이 누구인지 알아내는 게 목표입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 사진까지 파일 안에 들어 있어서 따로 설치할 것은 없습니다.

## 플레이 방법

1. 이름을 입력합니다. 등장인물들이 이 이름으로 플레이어를 부릅니다.
2. 잠금화면 비밀번호는 아무 숫자 4자리나 됩니다. 힌트가 "내 생일"이라, 입력한 숫자(월일)가 플레이어의 생일이 되고 멤버들에게 "내 생일 언제야?"라고 물으면 그 날짜로 대답합니다.
3. 인스타 스토리를 구경하다가 마음이 가는 스토리에 ♡를 누릅니다.
4. 잠시 뒤 카카오톡으로 `(알 수 없음)`에게서 연락이 옵니다.
5. 카톡은 직접 입력해서 대화합니다. 메시지에 키워드(뭐 해, 오늘 하루, 연락했어?, 안녕, 잘 자 등)가 들어 있으면 그에 맞는 답이 옵니다. 메시지를 오래 안 읽으면 상대가 먼저 다시 연락합니다.
6. 익명 채팅에서 "누구야", "힌트" 같은 말로 힌트를 받고, 여섯 명에게 카톡으로 질문하거나 다른 앱(연락처, 메모, 인스타, 인터넷 등)을 뒤져 단서를 찾습니다. 여섯 명 모두 플레이어를 좋아해서 쉽게 티가 나지 않습니다.
7. 익명 채팅에 이름을 써서(예: "혹시 종성이야?") 또는 「너 누구야?」 버튼으로 정답을 고릅니다. 기회는 3번입니다. 틀리면 "아닌데...", 두 번째엔 "진짜 모르는 거야..?". 한 번이라도 틀린 뒤 맞히면 못 맞출까 봐 무서웠다며 처음 고른 사람을 질투합니다.
8. 플러팅을 하거나 인스타 댓글을 달면 호감도가 오릅니다(최대 20). "좋아해"라고 하면 처음엔 장난으로 받고, "진짠데?"라고 하면 설레게 받아칩니다. 호감도가 20이 되면 ♡를 받지 않은 사람도 먼저 고백하고, 받아주면 똑같이 하트 스토리가 올라오고, "사랑해"로 답장하면 해피엔딩이 됩니다.
9. 맞히면 고백을 받습니다. 거절하면 배드엔딩, 받아주면 그 사람이 나를 태그한 하트 스토리를 올립니다(정원은 친한 친구 영상 스토리). 종성은 스토리 대신 전화로 "내가 올린 영상 봐줘"라고 한 뒤 유튜브에 영상을 올리고, 그 영상에 "사랑해" 댓글을 달면 해피엔딩입니다. 그 스토리에 "사랑해"로 답장하면 해피엔딩입니다.
