# 11:30

밤 11시 30분, 모르는 누군가에게서 "나 기억나?"라는 연락이 온다.
스마트폰 화면을 그대로 재현한 웹 게임으로, 나를 좋아하는 사람이 누구인지 알아내는 게 목표입니다.

## 실행

`index.html`을 브라우저로 열면 됩니다. 사진까지 파일 안에 들어 있어서 따로 설치할 것은 없습니다.

## 플레이 방법

1. 이름을 입력합니다. 등장인물들이 이 이름으로 플레이어를 부릅니다.
2. 잠금화면 비밀번호는 `0000`입니다.
3. 인스타 스토리를 구경하다가 마음이 가는 스토리에 ♡를 누릅니다.
4. 잠시 뒤 카카오톡으로 `(알 수 없음)`에게서 연락이 옵니다.
5. 카톡은 직접 입력해서 대화합니다. 메시지에 키워드(뭐 해, 오늘 하루, 연락했어?, 안녕, 잘 자 등)가 들어 있으면 그에 맞는 답이 옵니다. 메시지를 오래 안 읽으면 상대가 먼저 다시 연락합니다.
6. 익명 채팅에서 "누구야", "힌트" 같은 말로 힌트를 받고, 여섯 명에게 카톡으로 질문하거나 다른 앱(연락처, 메모, 인스타, 인터넷 등)을 뒤져 단서를 찾습니다. 여섯 명 모두 플레이어를 좋아해서 쉽게 티가 나지 않습니다.
7. 익명 채팅에 이름을 써서(예: "혹시 종성이야?") 또는 「너 누구야?」 버튼으로 정답을 고릅니다. 기회는 3번입니다.
8. 플러팅을 하거나 인스타 댓글을 달면 호감도가 오릅니다(최대 ♥10). "좋아해"라고 하면 처음엔 장난으로 받고, "진짠데?"라고 하면 설레게 받아칩니다. 호감도가 10이 되면 ♡를 받지 않은 사람도 먼저 고백하고, 받아주면 그 사람과 해피엔딩이 됩니다.
9. 맞히면 고백을 받습니다. 대답에 따라 해피엔딩 또는 배드엔딩이 나옵니다.

<summary>스포일러: 정답이 정해지는 방식과 추리 구조</summary>

스토리에 **가장 먼저 ♡를 누른 사람**이 그 판에 모르는 번호로 연락하는 사람이 됩니다.
♡를 누르지 않으면 연락이 오지 않습니다.

여섯 명은 아래 세 가지 특징의 조합이 모두 다릅니다. 익명 채팅의 힌트 3개가 각각 하나씩 **돌려서** 알려줍니다.
("처음 만났을 때 너 울고/웃고 있었잖아", "바람 불어서 손 시려 / 이불 속이라 따뜻하다", "나 원래 웃을 때 이렇게 웃잖아 ㅋㅋ/ㅎㅎ")
잠긴 메모에는 이름 대신 별명(js, 엄마 친구 아들, 내 베프, 동아리 선배, 같은 수업 걔, 알바 오빠)이 적혀 있어서 연락처·인스타와 맞춰 봐야 합니다.

| 특징 | 종성 | 성훈 | 선우 | 재윤 | 니키 | 정원 |
|---|---|---|---|---|---|---|
| 처음 만난 날 울고 있었음 = 어릴 때부터 앎 (🔒 잠긴 메모 「처음 만난 날들」, 암호 1130) | O | X | O | O | X | X |
| 말투 (카톡·댓글) | ㅋㅋ | ㅎㅎ | ㅎㅎ | ㅋㅋ | ㅋㅋ | ㅎㅎ |
| 지금 밖에 있음 (「지금 뭐 해?」) | O 야구장 | X 집에서 쉬는 중 | X 방금 씻음 | X 집에서 강아지랑 | O 춤 연습 가는 중 | O 잠깐 외출 |

연락한 사람에게 「혹시 방금 나한테 연락했어?」라고 물으면 살짝 당황합니다.
